# Campus Lost & Found Management System

A Java command-line application for managing lost and found items on a college campus.

## Features

- Student registration
- Report lost items
- Report found items
- Search item records
- Match lost and found items
- Submit and manage claims
- Store data using JDBC and H2
- Export item records to CSV

## Technologies

- Java 17
- JDBC
- H2 Database
- Maven
- Git/GitHub

## How to Run

```bash
mvn clean compile
mvn exec:java
