# Smart Campus Lost & Found Management System

Campus Lost & Found Management System is a Java-based command-line application designed to manage lost and found items within a college campus. It allows students to register items, search records, identify possible matches between lost and found items, and manage claims using a JDBC-connected H2 database.

## Features

- Student registration
- Report lost and found items
- Search item records
- Match lost and found items
- Claim management
- JDBC and H2 database
- CSV backup

## Technologies Used

- Java 17
- JDBC
- H2 Database
- Maven
- Git & GitHub

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/aryansrivastava3004/Smart-campus-Lost-and-Found-Management-System.git
```

### 2. Open the project

```bash
cd Smart-campus-Lost-and-Found-Management-System
```
### 3. Compile the project
```bash
mvn clean compile
```
### 4. Run the application
```bash
mvn exec:java
```
