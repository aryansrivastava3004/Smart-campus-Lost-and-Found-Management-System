# Project Statement

## Problem Statement
Students may lose personal belongings on campus and rely on informal messages to locate them. This makes searching, matching and claim tracking difficult.

## Scope
The system records users, lost items, found items and claims; supports search and possible-match scoring; stores data in an H2 database; and creates CSV backups.

## Target Users
- College students
- Campus lost-and-found administrators/volunteers

## High-Level Features
1. User registration
2. Lost/found reporting
3. Search
4. Rule-based matching
5. Claims
6. JDBC persistence
7. CSV backup
8. Background backup processing
